
# 🚀 Hazelnut Classification Project — Task Flow (PyTorch + MLflow)

```text
PROJECT GOAL:
Classify hazelnut images into:
- ok
- not_ok
```

---

# 🟢 1. Project Setup

```text
- Create project folder structure
- Install required libraries (torch, torchvision, mlflow, matplotlib)
- Initialize Git repository
```

---

# 🟢 2. Dataset Preparation

```text
- Collect and organize images
- Create folder structure:
    train/
      ok/
      not_ok/
    val/
    test/

- Split dataset (e.g., 70% train, 15% val, 15% test)
```

---

# 🟢 3. Check Class Distribution (IMPORTANT)

```text
- Count images in each class
- If one class >> other → dataset is imbalanced
- Note imbalance for later handling
```

---

# 🟢 4. Define Image Preprocessing

```text
- Resize images (e.g., 128x128)
- Normalize pixel values (0–1)

- Apply augmentation (ONLY for training):
    - flip
    - rotation
    - zoom
```

---

# 🟢 5. Create PyTorch Dataset & Dataloader

```text
- Use torchvision.datasets.ImageFolder
- Create DataLoader for:
    - train
    - validation
    - test
```

---

# 🟢 6. Handle Class Imbalance

```text
- Option 1: Apply more augmentation to minority class
- Option 2: Use class weights in loss function (recommended)

- Goal:
    Prevent model from predicting only one class
```

---

# 🟢 7. Build ANN Model (Baseline)

```text
- Flatten image
- Add fully connected (Linear) layers
- Use ReLU activation
- Output layer → sigmoid / softmax

- Purpose:
    Simple baseline for comparison
```

---

# 🟢 8. Build CNN Model (Main Model)

```text
- Add Conv2D layers
- Add ReLU activation
- Add MaxPooling
- Flatten → Fully connected layers

- Purpose:
    Capture spatial features from images
```

---

# 🟢 9. Define Training Components

```text
- Loss function (CrossEntropyLoss or BCE)
- Optimizer (Adam recommended)
- Learning rate
- Epochs
```

---

# 🟢 10. Implement Training Loop

```text
For each epoch:
    - Forward pass
    - Compute loss
    - Backpropagation
    - Update weights

- Track:
    - training loss
    - training accuracy
```

---

# 🟢 11. Implement Validation Loop

```text
After each epoch:
    - Evaluate on validation set
    - Track validation accuracy and loss

- Purpose:
    Detect overfitting
```

---

Hazelnut Classification Project Flow

Project Structure:
- data/raw → original images
- data/processed → train/val/test split
- src/ → all backend python files
- notebooks/main.ipynb → experiments, testing, visualization

Flow:
1. prepare_dataset.py
   - Takes images from data/raw
   - Creates train/val/test split inside data/processed
   - Runs only once initially

2. dataset.py
   - Loads processed dataset
   - Applies transforms and augmentation
   - Creates train_loader, val_loader, test_loader
   - Imported into train.py

3. model_ann.py
   - Contains ANN/Dense Neural Network architecture
   - Only defines model class

4. model_cnn.py
   - Contains CNN architecture
   - Only defines model class

5. train.py
   - Main training pipeline
   - Imports dataset loaders from dataset.py
   - Imports ANN or CNN model
   - Defines loss function and optimizer
   - Runs training + validation loop
   - Saves trained model (.pth)

6. notebooks/main.ipynb
   - Used for testing and experimentation
   - Load saved model
   - Predict on images
   - Plot accuracy/loss graphs
   - Compare ANN vs CNN
   - Create confusion matrix

Important Rules:
- dataset.py only handles data
- model files only define architectures
- train.py connects everything
- main.ipynb is for analysis/testing only

Execution Order:
prepare_dataset.py
   ↓
dataset.py
   ↓
model_ann.py / model_cnn.py
   ↓
train.py
   ↓
saved model (.pth)
   ↓
main.ipynb
